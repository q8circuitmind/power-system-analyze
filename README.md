# Power System Analyzer💡

Three-phase power system analysis engine.

## What it does
- Converts line-to-line voltage to phase voltage
- Computes apparent, active, and reactive power
- Solves for line current and complex impedance
- Separates resistance and reactance
- Classifies the load as inductive or capacitive

## Example
Input: 400 V, 50 kW, 0.85 power factor
Output: phase voltage, current, R, X, load type
